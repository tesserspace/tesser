It’s built for “first 60 seconds” users: pick a dataset, paste a small JS strategy, click run, and immediately see:

- **Candlestick chart** with **buy/sell markers**
- **Equity curve**
- **Key metrics** (return, max drawdown, Sharpe, fees, trades)

Try it here: **[/playground/backtest](/playground/backtest)**.

## Signal-style strategies (target weight)

Instead of writing order logic, your strategy returns a **target weight** and the engine handles rebalancing.

- If shorting is disabled: `target ∈ [0, 1]`
- If shorting is enabled: `target ∈ [-1, 1]`

Returning `null` / `undefined` means “keep current position”.

Here’s a minimal example (SMA cross):

```js
(ctx, { sma }) => {
  const fast = sma(ctx.close, 20);
  const slow = sma(ctx.close, 50);
  if (fast == null || slow == null) return null;
  return fast > slow ? 1 : 0;
}
```

You can tune:

- Initial equity

## What’s next

This is intentionally a minimal playground. The next upgrades we’re considering:

1. More symbols + longer history + on-demand downloads
2. Strategy templates (trend, mean-reversion, breakout)
3. Export / share links (strategy + params + dataset)
4. A stricter sandbox for user JS (timeouts, memory limits, restricted APIs)

If you want a specific dataset or template strategy added, open an issue or ping the team.
